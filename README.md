# Семейный бюджет

Одностраничное приложение (`index.html`): без сборки, без сервера, данные хранятся в браузере.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).

## Подключение Google Таблицы

1. Откройте таблицу «Семейный бюджет — база данных» на вашем Диске.
2. Расширения → Apps Script. Удалите содержимое, вставьте код из `apps-script/Code.gs`, сохраните.
3. Развернуть → Новое развёртывание → Тип: Веб-приложение. Выполнять от имени: Я. Доступ: Все, у кого есть ссылка. Нажмите «Развернуть» и разрешите доступ.
4. Скопируйте ссылку, которая заканчивается на `/exec`.
5. В приложении: Настройки → Google Таблица → вставьте ссылку.

После этого каждая операция уходит в лист «Операции». Синхронизация односторонняя: приложение → таблица. Обратная загрузка из таблицы в приложение пока не сделана.

## Структура

- `index.html` — приложение, данные за октябрь 2026 встроены как стартовые (CSV).
- `apps-script/Code.gs` — приёмник для Google Таблицы.
